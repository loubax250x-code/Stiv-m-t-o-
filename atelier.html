Atelier

Poser : touche une face pour poser le bloc choisi. Casser / Pipette : touche un bloc. Zone : touche 2 coins, le volume se remplit (choisis la Gomme pour vider une zone).
Camera : 1 doigt = tourner, 2 doigts = zoom + deplacer. PC : clic gauche poser, clic droit casser, glisser = tourner, clic droit glisse = deplacer, molette = zoom, WASD/ZQSD + Espace/Maj = deplacer, Ctrl+Z / Ctrl+Y.
Les gros traits de la grille = 1 chunk du jeu (8 blocs). Le sol est le niveau 0 : ton premier bloc est pose juste au-dessus. Ta construction est sauvegardee automatiquement dans ce navigateur.
